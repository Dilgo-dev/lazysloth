# 🦥 LazySloth

> Un client API simple, intuitif et efficace pour les développeurs

LazySloth est conçu pour simplifier le test et l'utilisation d'APIs avec une interface moderne et des fonctionnalités pensées pour le développement quotidien.

## ✨ Fonctionnalités

### 🚀 Requêtes HTTP complètes

- Support de tous les verbes HTTP (GET, POST, PUT, DELETE, PATCH)
- Gestion avancée des headers, paramètres et body
- Visualisation claire des réponses avec temps de réponse
- Historique des requêtes pour un accès rapide

### 📁 Workspaces

- Organisation par projet avec des workspaces dédiés
- Isolation complète entre les différents projets
- Collections de requêtes groupées logiquement
- Gestion multi-projets simplifiée

### 🔧 Variables d'environnement

- Variables personnalisées réutilisables : `{{BASE_URL}}`, `{{API_KEY}}`
- Changement d'environnement en un clic (dev/staging/prod)
- Syntaxe intuitive pour l'interpolation de variables
- Gestion centralisée des configurations

### ☁️ Synchronisation cloud

- Compte utilisateur simple (email + password)
- Synchronisation automatique sur tous vos appareils
- Partage de workspaces entre équipes
- Sauvegarde sécurisée de vos données

### 🎨 Interface moderne

- Design épuré et intuitif
- Mode sombre pour le confort visuel
- Interface responsive et rapide
- Optimisée pour de longues sessions de développement

## 🎯 Pourquoi LazySloth ?

LazySloth se distingue par sa **simplicité d'utilisation** sans sacrifier la puissance. Contrairement aux outils complexes existants, LazySloth se concentre sur l'essentiel : tester vos APIs rapidement et efficacement.

**Avantages clés :**

- Interface intuitive sans courbe d'apprentissage
- Variables d'environnement pour une gestion flexible
- Synchronisation cloud native
- Performance optimisée
- Focus sur l'expérience développeur
